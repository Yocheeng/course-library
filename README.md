# 課程學習站

作業系統與演算法課程題庫網站，提供分單元閱讀、搜尋篩選與練習作答，搭配答案解析和課間電台。

**線上網站：** [yocheng06.github.io/course-library](https://yocheng06.github.io/course-library/)

## 題庫

- 作業系統：4 個單元、370 題
- 演算法：3 個單元、180 題

網站中的題數依題庫資料自動計算。

## 功能

- **閱讀與搜尋**：可選「目前單元」或「全部單元（本課程）」搜尋題目、答案與解析；章節、題型、待確認與待複習篩選會套用到所選範圍。跨單元結果會標明來源單元。
- **待確認題目**：可篩選含核對提醒，或缺少選項、題圖、原答案或解析的題目，並查看待確認原因；作業系統的一般觀念補充備註不會自動列為待確認。此狀態不代表答案一定有誤。
- **回報更正**：每題提供 GitHub 回報表單入口（需登入），預填單元、題號、題目、目前答案與可定位題目的連結，送出前可補充修正及參考來源。
- **練習模式**：先作答再揭答；兩科使用相同的選項核對提示，文字題可先寫下解題想法。
- **待複習**：可手動標記題目，也可在選項核對錯誤後一鍵加入，並篩選所選搜尋範圍內的待複習題目。
- **手機閱讀**：支援單元切換、快速換頁與大字閱讀；題目標籤與主要輔助文字調整為 14px，操作鍵提供清楚焦點，換頁後焦點移至結果摘要，設定與手機導覽可用 Escape 收起。手機版底部操作列為電台按鈕預留位置，桌面版按鈕放在側欄。
- **課間電台**：提供播放、暫停、切歌、隨機播放與單曲重複，透過站內課程切換可繼續播放。

## 使用說明

1. 從首頁選擇科目與單元。
2. 使用閱讀模式查看題目，或切換練習模式自行作答。
3. 點選「對照答案與解析」查看結果，把想再練的題目加入待複習。

只有答案能明確對應選項的題目會自動核對；文字題或無法對應的答案需自行對照解析。

待複習標記與閱讀字級保存在目前裝置的瀏覽器，不會跨裝置同步。練習答案僅暫存在目前頁面，重新整理後會清除。

## 本機使用

下載或複製專案後，以瀏覽器開啟 `index.html`。這是純 HTML、CSS 與 JavaScript 網站，無需安裝套件或建置；請保留完整的 `assets/` 資料夾。

- `index.html`：網站首頁
- `os.html`：作業系統題庫
- `algorithms.html`：演算法題庫
- `music-player.html`：課間電台
- `assets/`：樣式、互動程式與媒體資源
