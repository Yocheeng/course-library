# 課程學習站

作業系統與演算法課程題庫網站，提供分單元閱讀、搜尋篩選與練習作答，搭配答案解析。

**線上網站：** [yocheng06.github.io/course-library](https://yocheng06.github.io/course-library/)

## 題庫

- 作業系統：5 個單元、476 題（含 L6 CPU 排程 106 題）
- 演算法：3 個單元、180 題

網站中的題數依題庫資料自動計算。

L6 合併自提供的 `作業系統 L6.html` 與 `作業系統L6_完整題庫本.html`。完整題庫的 210 筆資料先排除重複批次，再把中英文同題合併至同一張題卡；補入 5 道缺少的題目、合併 3 組既有重複題，最終共 106 題。63 題附完整選項，可用單選／多選方式練習；43 題採文字練習並保留特殊填答格式。舊題目連結及待複習標記會對應至合併後的題目。來源自述的公布答案尚未由本站核驗；未提供公布答案、答案衝突或題意疑點保留在待確認篩選中。

## 功能

- **閱讀與搜尋**：可選「目前單元」或「全部單元（本課程）」搜尋題目、答案與解析；章節、題型、待確認與待複習篩選會套用到所選範圍。跨單元結果會標明來源單元，搜尋結果也會標示命中題幹、選項、答案、解析、備註或分類；遮答模式只顯示命中位置，揭答前不顯示答案與解析內容。
- **待確認題目**：可篩選含核對提醒，或缺少選項、題圖、原答案或解析的題目，並查看待確認原因；作業系統的一般觀念補充備註不會自動列為待確認。此狀態不代表答案一定有誤。
- **解析與答案修正**：解析補充解題步驟、成立條件及反例，較長解析依核心觀念、判讀／解題步驟與適用條件分段。修正答案標示為「修正後答案」，並可展開查看修正前答案；題意矛盾或缺少解題資料的題目會暫停自動判分。詳細記錄與參考來源見 [題庫內容檢視](content-review.md)，題目畫面不顯示參考連結。
- **回報更正**：每題提供 GitHub 回報表單入口（需登入），預填單元、題號、題目、目前答案與可定位題目的連結，送出前可補充修正及參考來源。
- **練習模式**：先作答再揭答；兩科使用相同的選項核對提示，文字題可先寫下解題想法。
- **待複習**：可手動標記題目，也可在選項核對錯誤後一鍵加入，並篩選所選搜尋範圍內的待複習題目。
- **手機閱讀**：支援單元切換、快速換頁與大字閱讀；手機版縮短標題區，合併篩選入口與模式切換，搜尋範圍說明保留供輔助科技讀取。題目標籤與主要輔助文字調整為 14px，操作鍵提供清楚焦點，換頁後焦點移至結果摘要，設定與手機導覽可用 Escape 收起。

課間電台目前暫停使用：首頁與題庫不顯示電台入口，也不載入播放器、歌單、音檔或維持播放的課程 iframe。直接開啟舊播放器網址會顯示暫停使用與返回首頁連結。原播放器、歌單與音樂檔均保留。

若要恢復，將 `assets/music-feature.js` 中的 `MUSIC_RADIO_ENABLED` 改為 `true`，並更新四個 HTML 頁面載入此檔案的 `v` 版本參數。共用開關會恢復入口、播放器與切換課程時持續播放；手機底部也會重新為電台按鈕預留空間。

## 使用說明

1. 從首頁選擇科目與單元。
2. 使用閱讀模式查看題目，或切換練習模式自行作答。
3. 點選「對照答案與解析」查看結果，把想再練的題目加入待複習。

只有答案能明確對應選項、且未標記題意或解題資料疑點的題目會自動核對；文字題或無法對應的答案需自行對照解析。來源所述「平台已判分」不等於本站已登入學校系統核實。

待複習標記與閱讀字級保存在目前裝置的瀏覽器，不會跨裝置同步。練習答案僅暫存在目前頁面，重新整理後會清除。

## 本機使用

下載或複製專案後，以瀏覽器開啟 `index.html`。這是純 HTML、CSS 與 JavaScript 網站，無需安裝套件或建置；請保留完整的 `assets/` 資料夾。

- `index.html`：網站首頁
- `os.html`：作業系統題庫
- `algorithms.html`：演算法題庫
- `music-player.html`：課間電台（目前暫停使用，保留供恢復）
- `assets/`：樣式、互動程式與媒體資源
